# 文档目录说明

`docs/` 按文档用途划分目录，各文件夹的功能如下：

| 文件夹 | 功能 |
| --- | --- |
| [guide/](guide/) | 使用指南，包括构建安装、配置、运行、权限管理和工具使用；开发与验收流程（含 Windows 虚拟机验证）见 [workflow](guide/workflow.md)。 |
| [design/](design/) | 系统设计，记录当前架构、模块职责、接口和实现约定。 |
| [view-design/](view-design/) | 界面与交互设计，预留用于布局、操作流程和视觉方案。 |
| [research/](research/) | 技术调研，记录选型比较、方案探索和待评估建议。 |
| [report/](report/) | 实验报告，记录测试目标、参数、数据集、结果和分析。 |
| [archive/](archive/) | 历史归档，保存已结束的实施计划、验收记录和阶段性结论。 |
