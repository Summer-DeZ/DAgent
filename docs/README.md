# DAgent 文档

DAgent 是一个使用 C++23 和 CMake 构建的通用任务执行 Agent。它以 CLI 为入口，支持单次运行与持续终端会话，在工作区边界与三档授权模式下调用模型执行文件、进程和网络操作，并用 JSONL 事件与版本化 checkpoint 保存执行证据、支持崩溃恢复。仅支持 Linux。

## 目录约定

```
docs/
├── README.md        本索引
├── reference.md     一站式技术参考
├── status.md        实现状态
├── roadmap.md       未完成任务
├── plan.md          可用性提升计划
├── design/          设计文档：描述当前实现
├── guide/           使用说明
├── known-bugs/      当前问题清单：基于当前工作树的审查
└── archive/         历史归档：不再维护
```

- 目录名不含空格，避免 Markdown 链接需要转义。
- 设计文档描述现状，不描述目标能力；未实现的能力在对应文档的「已知缺口」小节列出，不混入正文。
- 代码改动后，同步更新对应的设计文档；新发现的问题记入 `known-bugs/`，修复后在条目中标注而不是删除条目。
- 遵循 [AGENTS.md](../AGENTS.md)：不创建测试代码、模拟模型或演示入口；功能修改通过构建和真实运行验证，验证材料只放在 `temp/`。
