# 主题配色与语义令牌设计

DAgent 终端界面采用语义化颜色令牌（`ThemeTokens`）与明暗双模式设计，内置唯一默认主题 `home/themes/dagent.json`，同时支持加载自定义主题文件与无真彩色终端的 256 色精确回退。

## 1. 视觉层次与语义令牌

界面不直接使用硬编码颜色，而是通过分组语义令牌表达层次：

| 类别 | 语义令牌 | 设计用途 |
| --- | --- | --- |
| **背景四层** | `background` / `background_panel` / `background_element` / `background_selected` | 页面主底色 / 侧栏与弹窗底色 / 用户消息与标签底色 / 列表与菜单当前选中行 |
| **文字三档** | `text` / `text_muted` / `text_faint` | 主正文 / 次要信息（工具参数、统计、分节标题）/ 弱化信息（行号、折叠提示、装饰挂钩、注释） |
| **强调与状态** | `primary` / `accent` / `success` / `warning` / `error` / `info` | 主强调色（默认橙色）/ 次级混合强调色 / 语义状态指示 |
| **边框与选区** | `border` / `border_active` / `selection` | 普通分隔边框 / 激活输入框与焦点弹窗边框 / 鼠标拖选高亮 |
| **专业视图** | `diff_*` / `syntax_*` / `markdown_*` | Diff 增删文字与行底色、代码语法高亮、Markdown 排版样式 |

**对比度约束**：`text_faint` 仅允许绘制在页面或面板底色上；在元素（`background_element`）或选中行（`background_selected`）底色上的次要文字必须使用 `text_muted`，保证可读性。

## 2. 动态适配与颜色推导

1. **明暗模式切换**：支持 `auto`（根据终端 OSC 11 报告的背景色自动选择暗色或亮色变体）、`dark` 和 `light`。
2. **背景模式**：
   - `solid`：使用主题定义的实心背景色。
   - `transparent`：将页面主背景设为终端默认透明色，其余面板与元素保持实心。
   - 自定义 `#rrggbb`：按相对亮度自动判定明暗，并向白色（暗底）或黑色（亮底）按比例混合推导面板、元素与选中行底色。在 `transparent` 与自定义背景模式下，Diff 增删行底色（`diff_added_bg` / `diff_removed_bg`）也会自动由 `success`/`error` 前景色按 15% 比例混入面板底色生成，防止 Diff 高亮失真。
3. **强调色（Accent）自适应对比度**：除内置预设（`orange`、`green`、`violet`、`blue`）外，用户提供自定义 `#rrggbb` 时，系统在 OKLab 色彩空间中保持色相不变、自动调整明度，确保在面板底色上的对比度达到 `4.5:1` 以上。

## 3. 主题文件格式与 256 色回退

主题 JSON 由颜色别名表 `defs` 以及 `dark`、`light` 两套令牌覆盖组成，未声明的令牌自动回退到内置默认值。

为兼顾真彩色（24-bit）与 256 色终端的显示效果，颜色定义支持多种写法：
- `"#rrggbb"`：真彩色直接输出 RGB，256 色终端自动按 xterm 色立方与灰阶最近距离量化。
- `{"rgb": "#21344f", "256": 17}`：真彩色使用精确 RGB，256 色终端优先使用手工调校的 xterm 显式索引（避免深色 Diff 底色在自动量化时失真）。
- `"default"` 或 `0`–`255` 整数：使用终端默认色或固定索引色。
