# workspace：文件原语、代码搜索、Diff 与环境采集

`workspace` 模块（`dagent_workspace`）为上层工具提供针对工作区底层资源的原子操作原语。

**职责边界**：
- 提供防篡改文件读写、基于 `ripgrep` 的受限代码搜索、Myers Unified Diff 生成、以及项目环境与 `AGENTS.md` 采集。
- **不包含面向模型的工具语义**：如「编辑前必须先读取」、「输出行号格式」或「权限审批策略」均由 `tools` 与 `agent` 层决定。

## 1. 路径解析与工作区边界

`resolve(root, path)` 将用户输入的相对或绝对路径规范化，并通过**逐个路径分量比对**（而非字符串前缀匹配）判定目标是否位于工作区根目录内（`inside_workspace`），供核心权限层决策。

## 2. 文件原语与防篡改句柄（`FileReference`）

模型发起的 `read` / `edit` / `write` 工具**不直接按字符串路径读写文件**，而是通过 `FileReference` 绑定底层文件对象，防止「准备/审批」与「实际落盘」之间发生符号链接替换（TOCTOU）或外部并发修改：

```mermaid
flowchart LR
    PREP["1. 准备阶段：固定已存在祖先目录与目标句柄，记录 Stamp"] --> AUTH["2. 核心审批与预览：校验 Stamp 未变，生成 Diff"]
    AUTH --> WRITE["3. 原子提交：在固定目录下写临时文件 → fsync → 再次校验 Stamp → 原子重命名"]
```

1. **句柄固定与防穿越**：在准备阶段即通过系统原语（Linux `O_PATH` + `openat2`，Windows `NtCreateFile`）固定已存在的祖先目录与目标对象，拒绝在后续操作中穿越新出现的符号链接、重定向点（reparse point）或命名数据流（ADS）。
2. **指纹校验（`Stamp`）**：记录文件的设备号、128 位 inode/File ID、大小与纳秒级修改时间。无论是预览还是最终写入，只要重开校验发现对象身份或 `Stamp` 变化，立即抛出 `stale` 错误要求重新读取。
3. **无损文本格式保留**：读取时自动识别文本编码、探测二进制（检查文件前 8 KiB 是否包含 `\0` 字节，若包含则拒绝读取报错）并剥离 BOM、将换行符统一转换为 LF 供内部处理；写回已有文件时自动还原原文件的换行风格（LF/CRLF）与 BOM，并保留原文件权限/ACL。
4. **原子替换与动态复验**：写入在目标同目录下创建独占临时文件，刷盘并再次核对指纹后原子替换目标（新建文件启用「禁止覆盖同名新文件」标志，防止覆盖准备期间外部刚创建的文件）；搜索等跨步操作也会在执行前后调用 `validate()` 动态校验目录句柄未发生偏移。

*(注：模块另提供轻量级 `probe` / `read_text` / `write_text` 供后端读取自身受信任配置文件使用。)*

## 3. 代码搜索与模糊匹配

- **沙箱内调用 `ripgrep`（`grep` / `files`）**：强制通过 `ReadOnlySandbox` 在无网络的只读 MXC 沙箱内运行托管 `rg`。支持在达到匹配数量上限（`max_matches` / `max_files`）或收到外部 `stop_token` 时提前终止子进程。
- **路径模糊排序（`fuzzy_rank`）**：内置移植的 `fzy` 打分算法，先按子序列快速过滤，再根据路径分隔符、驼峰边界与连续匹配计算得分，用于 `@` 文件补全和文件不存在时的相近路径推荐。

## 4. Unified Diff 计算与单文件 HEAD Diff

- **内存 Myers Diff**：基于 Myers 算法（`dtl`）在内存中的 `string_view` 行切片上计算差异，合并相邻变更块（hunk）并统计增删行数。当新旧文件均超过行数阈值（默认 20,000 行）时，自动退化为整文件替换模式，避免算法在超大文件上出现 $O((N+M)D)$ 性能退化。
- **单文件相对 HEAD 差异（`head_diff`）**：在只读沙箱内提取单个文件相对 Git `HEAD` 的统一差异（禁用外部 diff/textconv 工具，未跟踪文件自动构造为整文件新增 Diff），专门为会话内被修改脚本的权限复审（`script_diff`）提供确定性变更证据。

## 5. 项目上下文采集与模板渲染

会话启动时，`collect_environment` 采集工作区环境并经 `inja` 渲染进系统提示词模板（运行期状态栏刷新则调用轻量级 `collect_git_status`）：
- **并发只读 Git 采集**：在只读 MXC 沙箱内并发执行 `git rev-parse`、`git status` 与 `git log`（禁用可选锁、hooks 与 fsmonitor），任何一步失败均静默降级为空，不阻塞会话启动。
- **层级 `AGENTS.md` 收集**：从 Git 仓库根到当前 `cwd` 由外向内收集各层级的 `AGENTS.md`。若总大小超出预算（默认 32 KiB），**优先保留最靠近当前工作目录的内层指令**，由外向内依次截断或丢弃。
